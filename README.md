# Wathba Dev marketplace

This branch is generated by `.github/workflows/publish-dev.yml` from `main`.
Do not edit it: change `plugin.config.json` or `src/` on `main` instead.

It points at the Wathba development environment (`https://apidev.wathba.info/mcp`).

## Claude Code

```text
/plugin marketplace add wathba-org/wathba-plugin#dev
/plugin install wathba-dev@wathba-development
```

Then run `/mcp`, choose `wathba-dev` and sign in. Turn on updates under
`/plugin` → Marketplaces → `wathba-development` → Enable auto-update.

## Codex and the ChatGPT desktop app

```sh
codex plugin marketplace add wathba-org/wathba-plugin --ref dev
codex plugin add wathba-dev@wathba-development
```

Installing from the app's Plugins page starts sign-in; in a terminal run
`codex mcp login wathba-dev`.

## Moving from the old DEV marketplace

The marketplace keeps its name, so remove the old one first:

```text
/plugin marketplace remove wathba-development          # Claude Code
codex plugin marketplace remove wathba-development     # Codex
```

Then add this branch as above, sign in, and check that only one `wathba-dev`
server is listed (`/mcp` in Claude Code, `codex mcp list` in Codex).
